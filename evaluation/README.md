# Evaluation Question Set

This folder contains the complete question set prepared for the evaluation of the Moodle LLM Assistant prototype.

The questions are organised into three evaluation scopes:

- Storing and Retrieving Data;
- Machine Learning;
- Global institutional and regulatory content.

Within each scope, the questions are grouped by lecture material, thematic block or regulatory document. Most course-specific questions are written in English, while most institutional questions are written in Portuguese. A smaller number of cross-language questions were included to examine bilingual retrieval and answer behaviour.

The question set supported the evaluation reported in Chapter 5 of the project work. It includes factual, conceptual, procedural and regulation-specific questions. Repeated tests, reformulations and bilingual variants recorded during execution are reflected in the evaluation logs but are not necessarily represented as separate entries in this source question bank.
