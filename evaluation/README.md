# Evaluation Question Set

This folder contains the complete source question bank prepared for the evaluation of the Moodle LLM Assistant prototype.

The question bank is organised into three evaluation scopes:

- Storing and Retrieving Data;
- Machine Learning;
- global institutional and regulatory content.

Within each scope, the questions are grouped by lecture material, thematic block or regulatory document. Most course-specific questions are written in English, while most institutional questions are written in Portuguese. A smaller number of cross-language questions were included to examine bilingual retrieval and answer behaviour.

The source question bank contains 408 numbered entries. Some entries intentionally use the same wording in different programme-specific sections and therefore refer to different documentary contexts.

The evaluation dataset analysed in Chapter 5 comprises 405 logged interactions rather than 405 distinct questions. It includes repeated executions, while some entries from the source question bank were not executed. Consequently, the numbered entries in the question bank do not correspond one-to-one with the interactions reported in the evaluation.

The questions cover factual, conceptual, procedural and regulation-specific information needs across the three evaluation scopes.

## Available file

- `evaluation_questions.pdf` — complete source question bank containing 408 numbered entries.

## Evaluation scope

The question bank and supporting material are included for research transparency and reproducibility. They are not required for the runtime operation or installation of the Moodle plugin and should normally be excluded from deployment packages.
